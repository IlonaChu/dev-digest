# L01 — Run Cost Badge (server)

## Goal
Persist and expose the USD cost of every agent run so the UI can show it. Cost is data we already
have — `reviewer-core` returns `outcome.costUsd` (OpenRouter `usage.cost`, else tokens × price via
`PriceBook`/`estimateCost`) — it was simply dropped by `run-executor`. **Zero extra model calls.**

## Scope
**In**
- `agent_runs.cost_usd` (nullable `double precision`) written when a run completes.
- `cost_usd` on the run timeline (`RunSummary`), the run trace (`RunStats`) and the PR list (`PrMeta`).

**Out**
- Backfill of runs created before this feature (they stay `null` → UI shows "—").
- Summing cost per PR or per multi-agent batch (there is no `batch_id`; see Open points).
- CI runs (`ci_runs.cost_usd` is a separate table), price-book changes, the PR Overview verdict card.

## API / contracts
Canonical in `server/src/vendor/shared/contracts`, mirrored by hand into `client/src/vendor/shared`
(the copies have drifted — apply the same edits, never copy the file).

| Contract | Change |
|---|---|
| `trace.ts` › `RunStats` | `cost_usd: number \| null \| undefined` — nullish so traces persisted earlier still parse |
| `trace.ts` › `RunSummary` | `cost_usd: number \| null` — `GET /pulls/:id/runs` |
| `platform.ts` › `PrMeta` | `cost_usd: number \| null \| undefined` — `GET /repos/:id/pulls`, list endpoint only |

DB: `ALTER TABLE agent_runs ADD COLUMN cost_usd double precision` — migration `0010_*` generated by
`pnpm db:generate` (never hand-edited); apply with `pnpm db:migrate`.

Semantics: `null` = unknown (model has no price, failed/cancelled run, or pre-feature run). `0` = a
genuinely free model. Never store `0` for "no data".

`GET /repos/:id/pulls` → `cost_usd` is the cost of the **run that produced the latest review** of that
PR (resolved `reviews.run_id → agent_runs.cost_usd`, one extra `IN` query, no N+1); `null` if the PR was
never reviewed or that run has no cost.

## Acceptance criteria
1. A completed run stores `agent_runs.cost_usd = outcome.costUsd`; `run_traces.stats.cost_usd` matches.
2. Failed / cancelled runs store `null`.
3. `GET /pulls/:id/runs` returns `cost_usd` per run.
4. `GET /repos/:id/pulls` returns the latest review's run cost, `null` when unreviewed.
5. A trace without `stats.cost_usd` still passes `RunTrace.parse`.
6. The number of LLM calls per review is unchanged (test: stored cost == calls × mock price).
7. `pnpm typecheck && pnpm test` green (integration tests must actually run — Docker up).

## Open points / deviations
- "Latest review" is a single run. With *Review all* (several agents), the list shows one agent's cost,
  not the batch total. A real batch total needs a `batch_id` on `agent_runs`.
